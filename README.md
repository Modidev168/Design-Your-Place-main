# 🏠 Design Your Place

A complete Interior Design Web Application built using Python and Django.  
This project allows clients to select design packages and get assigned professional designers by the admin.

---

## 🚀 Features

- 🔐 User Authentication (Login & Registration)
- 👤 Role-Based Access (Admin, Designer, Client)
- 🎨 Portfolio Section with Categories:
  - Living Room
  - Bedroom
  - Child Room
  - Study Room
  - Bathroom
  - Kitchen
  - Store Room
- 📦 Package Selection System
- 👨‍🎨 Designer Assignment by Admin
- 🔄 Forget Password Functionality

---

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

---

## 📂 Project Structure

- Admin assigns designers to clients
- Clients select interior packages
- Designers manage portfolio designs
- Secure authentication system

---

## 💻 How to Run This Project

1. Clone the repository:
   git clone https://github.com/Modidev168/Design-Your-Place-main.git

2. Navigate to project folder:
   cd Design-Your-Place

3. Install dependencies:
   pip install -r requirements.txt

4. Run the server:
   python manage.py runserver
